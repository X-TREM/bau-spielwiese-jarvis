# bau-spielwiese-jarvis

Übungs-Repo für den Bau-Agenten der Zentrale. Hier liegen nie Geheimnisse, Kundendaten oder produktiver Code.

- Der Bau-Agent darf nur auf Branches `bau/**` pushen. `main` und alle anderen Branches sind per Ruleset geschützt.
- GitHub Actions sind abgeschaltet. Kein Deploy hängt an diesem Repo.
